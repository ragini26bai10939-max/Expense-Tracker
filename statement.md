## Project Statement

## Project Title

Expense Tracker

## Problem Statement

Managing daily expenses manually can be difficult when there are multiple expenses throughout the day. It can also become difficult to remember where money was spent and calculate the total amount spent.

The Expense Tracker provides a simple solution by allowing users to record and manage their daily expenses using a desktop application.

## Scope

The project focuses on basic personal expense management.

The application allows users to:

-Add expenses
-View expenses
-Edit expenses
-Delete expenses
-Filter expenses by category
-Calculate total spending
-View expenses using a bar chart

The project is designed for simple personal expense tracking.

## Target Users

The target users of the application are:

-Students
-Individuals who want to track their daily expenses
-Users who need a simple expense management application

## High-Level Features

## 1. Add Expense

Users can enter the amount, category, description, and date of an expense. The information is stored in the SQLite database.

## 2. View Expenses

All saved expenses are displayed in a table.

## 3. Edit Expense

Users can select an existing expense and update its details.

## 4. Delete Expense

Users can select an expense and delete it from the database.

## 5. Filter Expenses

Users can filter expenses according to categories such as Food, Travel, Shopping, Education, Bills, Entertainment, and Other.

## 6. Calculate Total Spending

The application calculates and displays the total amount spent.

## 7. Expense Chart

The application displays a bar chart showing the amount spent in each category.

## Technologies Used

-Python
-Tkinter
-SQLite
-Matplotlib

## Expected Outcome

The expected outcome is a simple and functional desktop application that allows users to record, manage, and analyse their daily expenses in one place.
